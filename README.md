**NexusAI** is an advanced SecOps intelligence platform engineered to bridge the gap between **Cybersecurity Telemetry**, **Data Science / Analytics**, and **Machine Learning Outlier Detection**. It processes security event streams, visualizes attack vectors (DDoS, SQLi, Brute-Force), flags anomalies via statistical algorithms, and provides actionable incident response via an integrated AI SecOps Copilot.

---

## 🚀 Key Architectural Pillars

- 🔍 **Real-Time Threat Telemetry**: Streaming security event parser for Auth, Nginx, and Firewall logs.
- 📊 **Data Science & Visualization**: High-fidelity time-series telemetry charts, threat distribution heatmaps, and severity gauges.
- 🧠 **ML Anomaly Detection**: Statistical Z-Score, IQR, and Isolation Forest algorithms to detect abnormal traffic spikes and stealth attacks.
- 🤖 **AI SecOps Copilot**: Autonomous threat synthesis, MITRE ATT&CK mapping, and automated remediation recommendations.
- ⚡ **Modern Stack**: Built with React 18, TypeScript, Tailwind CSS, Lucide Icons, and Vite for blazing-fast performance.

## 🛠️ Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **yarn** / **pnpm**

### Installation
```bash
# 1. Clone repository
git clone https://github.com/your-username/nexus-ai.git

# 2. Navigate to project directory
cd nexus-ai

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:3000` to access the NexusAI platform.
